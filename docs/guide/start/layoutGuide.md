# 布局指南

设计器支持三种表单布局模式，通过表单组件的「表单模式」属性切换。

## 表单模式

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| **普通** | 默认模式，字段垂直排列，每行一个字段 | 简单表单、字段较少的场景 |
| **网格** | 多列栅格布局，字段按网格排列，支持跨列 | 字段较多、需要紧凑排列的场景 |
| **行内** | 所有字段水平排列在一行 | 搜索栏、筛选条件等简单场景 |

## 网格布局

### 配置方式

1. 选中画布中的**表单**组件
2. 在右侧属性面板中找到「表单模式」，选择「网格」
3. 设置「栅格列数」（2-4 列）

### 字段占列

网格模式下，每个字段支持单独设置占列宽度：

1. 选中画布中的字段组件
2. 在右侧属性面板中找到「栅格占列」属性
3. 设置 1 到总列数之间的值

例如：表单设置为 4 列网格，某个字段设置「栅格占列」为 2，则该字段横跨 2 列宽度。

### 效果示例

```
4 列网格布局示例：
┌──────────────┬──────────────┬──────────────┬──────────────┐
│  字段 A      │  字段 B      │  字段 C      │  字段 D      │
│  (span=1)    │  (span=1)    │  (span=1)    │  (span=1)    │
├──────────────┴──────────────┼──────────────┬──────────────┤
│  字段 E (span=2)            │  字段 F      │  字段 G      │
│                             │  (span=1)    │  (span=1)    │
├──────────────┬──────────────┴──────────────┴──────────────┤
│  字段 H      │  字段 I (span=3)                          │
│  (span=1)    │                                            │
└──────────────┴────────────────────────────────────────────┘
```

## 卡片网格

卡片（Card）组件也支持网格布局。选中卡片后，在属性面板中开启「网格启用」并设置栅格列数，卡片内部的子字段将按网格排列。

## 兼容性说明

- 网格布局目前在 **Element Plus** 适配中完整支持
- 字段级 `span` 配置仅在父容器开启网格模式时生效
- 行内模式会忽略字段的栅格占列设置
