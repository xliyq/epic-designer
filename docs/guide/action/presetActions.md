# 预制动作

设计器内置了 9 个开箱即用的预制动作，可在组件的事件配置中直接使用，无需编写代码。

## 使用方式

1. 选中画布中的组件
2. 在右侧属性面板找到「事件」配置
3. 选择组件支持的事件（如 `change`、`click` 等）
4. 点击「添加动作」，选择预制动作
5. 配置动作参数

## 动作列表

### 提示消息 `showNotification`

显示一条消息提示。

| 参数 | 类型 | 说明 |
|------|------|------|
| 消息类型 | select | 成功 / 信息 / 警告 / 错误 |
| 提示内容 | input | 消息文本内容 |

### 打开链接 `openLink`

打开指定 URL 链接。

| 参数 | 类型 | 说明 |
|------|------|------|
| 链接地址 | input | 要打开的 URL |
| 打开方式 | select | 新窗口 `_blank` / 当前窗口 `_self` |

### 调用 API `callApi`

发送 HTTP 请求调用指定 API。

| 参数 | 类型 | 说明 |
|------|------|------|
| 请求地址 | input | API 地址 |
| 请求方式 | select | GET / POST / PUT / DELETE |
| 请求参数(JSON) | input | 可选，JSON 格式的请求体 |

### 确认对话框 `showConfirm`

弹出一个确认对话框，用户确认后继续执行后续动作。

| 参数 | 类型 | 说明 |
|------|------|------|
| 提示内容 | input | 对话框提示文本 |
| 标题 | input | 对话框标题（默认"提示"） |

### 下载文件 `downloadFile`

从指定地址下载文件到本地。

| 参数 | 类型 | 说明 |
|------|------|------|
| 文件地址 | input | 文件下载 URL |
| 文件名 | input | 可选，自定义文件名（默认自动识别） |

### 复制到剪贴板 `copyToClipboard`

将指定文本复制到系统剪贴板。

| 参数 | 类型 | 说明 |
|------|------|------|
| 文本内容 | input | 要复制的内容 |

### 控制台输出 `consoleLog`

在浏览器控制台输出信息，用于调试。

| 参数 | 类型 | 说明 |
|------|------|------|
| 输出内容 | input | 要输出的内容 |

### 设置本地存储 `setLocalStorage`

将数据写入 `localStorage`。

| 参数 | 类型 | 说明 |
|------|------|------|
| 键名 | input | 存储键名 |
| 存储值 | input | 要存储的值（自动转为 JSON） |

### 获取本地存储 `getLocalStorage`

从 `localStorage` 读取数据。

| 参数 | 类型 | 说明 |
|------|------|------|
| 键名 | input | 要读取的键名 |

## 动作编排

一个事件可以绑定多个动作，多个动作按配置顺序依次执行。例如：先调用 API 获取数据，再提示消息告知用户操作结果。
